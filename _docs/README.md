このディレクトリ（`_docs/`）は、Codex カスタムの参考資料置き場です。

- 背景・検討メモ・参考リンクなど、実装に必要な補助資料を追加します。
- 上流の更新（rebase/merge）を取り込みやすくするため、既存の `docs/` やリポジトリ内ドキュメントを大きく書き換えず、追加資料はここに寄せます。

## 目次

- `customization.md`: カスタム手順・運用ルール（日本語）
- `_docs/docs/`: 上流ドキュメントの日本語メモ（原本は編集しない）
- `_worklist/`: 一時的なタスクリスト
- `_docs/trace_name/`: Langfuse OTEL の trace name 切り分け・ログ分離検討
